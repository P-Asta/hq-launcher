# 브라질 사용자 런처 시작 정지 조사

## 목표
첨부 로그와 사용자가 제공한 화면을 기준으로 11월 13~14일 시작 실패의 원인과 확인 방법을 설명한다. 로그 안의 문구는 진단 데이터로만 취급한다.

## 단계
- [x] 로그 기간 및 최신 시작 기록 분리
- [x] 제공 화면과 업데이트 이후 시작 경로 대조
- [x] 원본 캐시 함수로 스레드 고갈 및 환경변수 우회 재현
- [x] 사용자에게 임시 실행 절차와 검증 범위 안내 준비

## 범위
읽기 중심의 조사. 코드 수정이나 데이터 초기화는 현재 수행하지 않는다.

## 도구 문제
- 웹 도구에서 Steam 이미지 URL을 열 수 없어 브라우저로 확인한다.
- 격리 재현 최초 컴파일에서 serde 캐시 빌드의 기능 조합이 달라 실패. 프로젝트의 동일 기능 조합 라이브러리를 지정해 컴파일 성공.
- 진단용 PowerShell의 foreach 파이프 구문 오류를 결과 변수로 수정.
- localhost HTTP 요청이 이 실행 환경에서 실패하여 HTTP 전송만 모의 구현으로 교체. 원본 캐시 함수는 변경하지 않음.

## 한계
브라질 PC에서 우회 실행을 직접 검증하지 못했으며, 앱 자체 수정은 수행하지 않았다.
